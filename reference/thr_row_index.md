# Position of each sample and marker in the per-sample threshold rows

Position of each sample and marker in the per-sample threshold rows

## Usage

``` r
thr_row_index(thr_rows)
```

## Arguments

- thr_rows:

  list of one-row data frames carrying `sample_id` and `marker`, as the
  pipeline collects them.

## Value

integer positions named "\<sample_id\>\r".
