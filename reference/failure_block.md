# Assemble the diagnosis block placed at the top of a failed run's report

Assemble the diagnosis block placed at the top of a failed run's report

## Usage

``` r
failure_block(err, outdir, opt = NULL)
```

## Arguments

- err:

  a condition, or a character message.

- outdir:

  the results directory, used to say what survived.

- opt:

  parsed options.

## Value

a character string of HTML.
