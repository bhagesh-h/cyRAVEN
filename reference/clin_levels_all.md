# Every category a clinical variable takes

Sorted, blanks and missing values dropped. A figure that shows a subset
of the samples builds its palette from this full list, so a category
keeps its colour from one figure to the next.

## Usage

``` r
clin_levels_all(v)
```

## Arguments

- v:

  the variable, one value per sample.

## Value

a character vector, or NULL for a numeric variable.
