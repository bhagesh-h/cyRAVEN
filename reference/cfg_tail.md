# The tail-gate side a `thresholds:` configuration entry declares

`{tail: lower}` declares that the marker's dominant mode in its parent
is the positive population; see
[`tail_gate_cut()`](https://bhagesh-h.github.io/cyRAVEN/reference/tail_gate_cut.md).

## Usage

``` r
cfg_tail(v)
```

## Arguments

- v:

  the entry, or NULL.

## Value

`"lower"` where declared, `"upper"` otherwise.
