# Format a p-value the way these figures conventionally annotate them

Format a p-value the way these figures conventionally annotate them

## Usage

``` r
p_annotation(p, style = c("stars_and_trend", "stars", "numeric"))
```

## Arguments

- p:

  The p.

- style:

  The style. Default `c("stars_and_trend", "stars", "numeric")`.
