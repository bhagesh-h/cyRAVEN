# Is this population label the catch-all remainder rather than a real lineage?

Matches the label this package assigns plus the conventional spellings
an imported or hand-edited table may carry, so a caller reasoning about
coverage cannot miss the remainder on a technicality of spelling.

## Usage

``` r
is_catch_all_label(x)
```

## Arguments

- x:

  Character vector of population labels.

## Value

Logical vector, `TRUE` where the label is a catch-all.
