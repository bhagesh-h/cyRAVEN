# Publication-oriented minimal theme WHY: consistent, legible defaults across every emitted figure; outward ticks and frameless legends read better in print than ggplot2 defaults.

Publication-oriented minimal theme WHY: consistent, legible defaults
across every emitted figure; outward ticks and frameless legends read
better in print than ggplot2 defaults.

## Usage

``` r
theme_cyto(base_size = 11, colors = fcs_colors())
```

## Arguments

- base_size:

  Base font size in points. Default `11`.

- colors:

  Named list of colours; defaults to the package palette. See
  [`fcs_colors()`](https://bhagesh-h.github.io/cyRAVEN/reference/fcs_colors.md).
  Default
  [`fcs_colors()`](https://bhagesh-h.github.io/cyRAVEN/reference/fcs_colors.md).
