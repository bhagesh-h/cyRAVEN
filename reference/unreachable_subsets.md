# Report which canonical subsets the panel cannot reach, and why

Written to the log so a reader knows the absence of a subset is a
property of the panel rather than of the cohort. A missing label that is
never mentioned reads as a population that was looked for and not found.

## Usage

``` r
unreachable_subsets(markers)
```

## Arguments

- markers:

  Character vector of marker names present in the panel.

## Value

Character vector of one sentence per unreachable group.
