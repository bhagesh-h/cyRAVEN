# The fixed cut a `thresholds:` configuration entry declares, if any

An entry is a bare number, or a list as
[`write_config()`](https://bhagesh-h.github.io/cyRAVEN/reference/write_config.md)
emits it (`threshold`, `source`, `needs_review`, and optionally `tail`).

## Usage

``` r
cfg_threshold(v)
```

## Arguments

- v:

  the entry, or NULL.

## Value

a number, or NULL.
