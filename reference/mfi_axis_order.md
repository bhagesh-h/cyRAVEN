# Row and column order for the MFI figures

Row and column order for the MFI figures

## Usage

``` r
mfi_axis_order(d, label_col, cluster_rows = FALSE)
```

## Arguments

- d:

  Rows for the "All samples" group of one panel.

- label_col:

  Label column.

- cluster_rows:

  Order rows by hierarchical clustering; otherwise keep the order they
  arrive in, which for declared populations is the order the
  specification lists them.
